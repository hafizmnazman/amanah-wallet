## Cloud sessions: installing Foundry

If the cloud network policy blocks `foundry.paradigm.xyz` and `binaries.soliditylang.org`, three workarounds were used and tested on 18 October 2026:

- **Foundry.** `npm install -g @foundry-rs/forge@1.7.1 @foundry-rs/anvil@1.7.1 @foundry-rs/cast@1.7.1`.
- **Exit codes.** The npm wrapper always exits 0, even when tests fail. Put the native binaries first on PATH:
  ```bash
  for t in forge anvil cast; do
    ln -sf "$(npm root -g)/@foundry-rs/$t/node_modules/@foundry-rs/$t-linux-amd64/bin/$t" ~/.local/bin/$t
  done
  ```
- **solc 0.8.26.** Do a sparse git clone of `github.com/ethereum/solc-bin`, check the binary's sha256 against `linux-amd64/list.json`, and copy it to `~/.svm/0.8.26/solc-0.8.26`. Forge then finds it without downloading.
- **gitleaks.** `go install github.com/zricethezav/gitleaks/v8@latest`.
